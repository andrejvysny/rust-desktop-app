# Asset attribution

All repository assets must be original, public domain/CC0, permissively licensed, or appropriately
attributed redistributable material. Each asset file needs a row with its author, source and
license. `cargo xtask assets` validates coverage; review license terms before adding material.

The minimal template bundles no custom image, icon or font files. Its UI uses toolkit defaults;
any icons drawn in Rust are covered by the source license. Marker files are not assets.
